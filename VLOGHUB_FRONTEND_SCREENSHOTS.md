# VlogHub Frontend Screenshots

Captured from the local Next.js frontend at `http://localhost:3000` with the Django backend running on `http://127.0.0.1:8000`.

Image files are kept in [screenshots](screenshots), and the slideshow is saved as [VlogHub_Picture_Presentation.pptx](VlogHub_Picture_Presentation.pptx).

The root route redirects to the login page in this build, so the login screen is the homepage entry point.
